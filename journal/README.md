# RHL Journal app

Rainford's RHL_FX trading journal as an installable phone app: dashboard, graded trade log (RHL Trade Grader rules), calendar, playbook stats, daily journal, MT5 report import.

- Works on its own: trades save on the device.
- Optional sync: connect a free Supabase project in **Settings** after running `supabase-setup.sql` once.
- Hosted by Netlify from this folder (see `../netlify.toml`).
